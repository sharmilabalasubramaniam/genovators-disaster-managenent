SAHYAT QUICK START

1. Double-click START-SAHYAT.bat
2. Wait for the browser to open
3. Sahyat opens automatically

Frontend:
http://localhost:5173

Backend:
http://127.0.0.1:8000

API Docs:
http://127.0.0.1:8000/docs

To stop:
Double-click STOP-SAHYAT.bat

To create a Desktop Shortcut:
1. Right-click START-SAHYAT.bat
2. Select "Send to" > "Desktop (create shortcut)"
3. Rename the shortcut on your desktop to "SAHYAT - Start"
